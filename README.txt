NEXORA — PREMIUM ELECTRONICS STORE CONCEPT

Project contents
- index.html: homepage with 4 featured products
- shop.html: full catalogue with category filters and product detail pop-up
- categories.html: category landing page
- about.html: project/brand concept page
- assets/js/data.json: 18 product records
- assets/css/: page styles
- assets/js/: homepage and shop functionality
- assets/images/: original project product and hero images

Run locally
1. Open this folder in Visual Studio Code.
2. Install/use the Live Server extension.
3. Right-click index.html and choose Open with Live Server.
4. Browse Home, Shop, Categories and About.

Notes
- Home intentionally shows only the first 4 products.
- Shop shows all 18 products. Category filters can be combined.
- VIEW DETAILS opens the product information pop-up.
- Product names, descriptions, prices and specifications are illustrative portfolio/demo content, not verified retail listings.
- Keep the assets folder structure unchanged so image paths continue to work.
