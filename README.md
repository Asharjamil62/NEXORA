# NEXORA

A premium tech-gadget storefront concept created as a web development portfolio project by VOID GENEX.

## Overview

NEXORA is a demo storefront built with HTML, CSS, JavaScript, and JSON product data. It showcases a dark, futuristic interface for browsing premium technology products.

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON

## Notes

Product names, prices, and specifications are illustrative demo content and are not live purchase offers.

## Project status

Portfolio/demo project. Some features may be presentation-only and are not connected to a production payment or order system.
